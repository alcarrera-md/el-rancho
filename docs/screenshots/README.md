# Capturas de pantalla

Imágenes que usa el `README.md` principal. Tómalas **solo con datos de
demostración** (`database/seed.sql` y `database/datos_prueba_completos.sql`), nunca
con la base del cliente, y revisa que no aparezcan correos, teléfonos, fotos de
animales reales, la URL de un túnel ni la barra de direcciones con IPs.

| Archivo | Qué mostrar | Tamaño sugerido |
|---|---|---|
| `01-inicio.png` | Panel de inicio con resumen del hato y alertas | 1440×900 |
| `02-seguimiento-animal.png` | Espacio de seguimiento de un animal (línea de tiempo y recomendaciones) | 1440×900 |
| `03-animales.png` | Inventario de animales con estado de salud | 1440×900 |
| `04-corrales.png` | Corrales con ocupación vs. capacidad | 1440×900 |
| `05-asistente.png` | Chat del asistente respondiendo una consulta | 1440×900 |
| `06-movil-oscuro.png` | Vista móvil en modo oscuro (DevTools → 390×844) | 390×844 |

Recomendaciones:

- Formato PNG (o WebP), cada archivo de menos de 500 KB.
- Usa el usuario `admin@rancho.com` de la base de demostración, no una cuenta real.
- Si cambias los nombres de archivo, actualiza la sección *Capturas de pantalla*
  del `README.md`.
